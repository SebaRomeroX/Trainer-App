# ============================================
# BODY TRAINER APP - DEVELOPMENT ROADMAP
# ============================================
# A trainer-client fitness platform
# Last updated: 2026-09-02

---

## PROJECT OVERVIEW
- **App Name**: Body Trainer App
- **Type**: Web Application (Mobile-responsive)
- **Purpose**: Trainer-client fitness platform for exercise creation, routine management, and progress tracking
- **Team**: Solo Developer
- **Target Launch**: MVP in 1-3 months
- **License**: Free / Open Source

---

## TECH STACK

### Frontend
- **Framework**: Next.js 14+ (App Router)
- **UI Library**: React 18+
- **Styling**: Tailwind CSS + shadcn/ui components
- **State Management**: React Context + Zustand (if needed)
- **Form Handling**: React Hook Form + Zod validation
- **Icons**: Lucide React

### Backend
- **Runtime**: Next.js API Routes (Route Handlers)
- **Authentication**: Custom JWT-based auth
  - Access tokens (short-lived)
  - Refresh tokens (long-lived, httpOnly cookies)
  - Password hashing: bcrypt/argon2
- **Validation**: Zod schemas
- **File Storage**: Cloudinary or Uploadthing (for exercise images/videos)

### Database
- **Primary DB**: MongoDB (via Mongoose ODM)
- **Caching**: Upstash Redis (optional, for rate limiting)

### Deployment & Infrastructure
- **Hosting**: Vercel (serverless)
- **Database Hosting**: MongoDB Atlas (free tier)
- **CI/CD**: GitHub Actions
- **Monitoring**: Vercel Analytics + Sentry (optional)
- **Email**: Resend or Nodemailer (transactional emails)

### Dev Tools
- **Package Manager**: pnpm
- **Linting**: ESLint + Prettier
- **Type Checking**: TypeScript strict mode
- **Git Hooks**: Husky + lint-staged

## DATABASE SCHEMA

### Collections

#### users
```
{
  _id: ObjectId
  email: String (unique, indexed)
  password: String (hashed)
  name: String
  role: Enum ["trainer", "client"]
  avatar: String (URL)
  createdAt: Date
  updatedAt: Date
}
```

#### trainer_profiles
```
{
  _id: ObjectId
  userId: ObjectId (ref: users)
  bio: String
  specialties: [String]
  clients: [ObjectId] (ref: users)
  maxClients: Number
}
```

#### client_profiles
```
{
  _id: ObjectId
  userId: ObjectId (ref: users)
  trainerId: ObjectId (ref: users)
  fitnessLevel: Enum ["beginner", "intermediate", "advanced"]
  goals: [String]
  notes: String
  startDate: Date
}
```

#### exercises
```
{
  _id: ObjectId
  trainerId: ObjectId (ref: users)
  name: String
  description: String
  category: Enum ["strength", "cardio", "flexibility", "balance", "other"]
  muscleGroups: [String]
  equipment: [String]
  difficulty: Enum ["easy", "medium", "hard"]
  videoUrl: String (optional)
  imageUrl: String (optional)
  createdAt: Date
}
```

#### routines
```
{
  _id: ObjectId
  trainerId: ObjectId (ref: users)
  name: String
  description: String
  difficulty: Enum ["beginner", "intermediate", "advanced"]
  duration: Number (estimated minutes)
  exercises: [{
    exerciseId: ObjectId (ref: exercises)
    sets: Number
    reps: Number
    duration: Number (for time-based)
    restTime: Number (seconds)
    notes: String
    order: Number
  }]
  isTemplate: Boolean
  createdAt: Date
  updatedAt: Date
}
```

#### client_routines
```
{
  _id: ObjectId
  clientId: ObjectId (ref: users)
  routineId: ObjectId (ref: routines)
  assignedDate: Date
  startDate: Date
  endDate: Date
  status: Enum ["active", "completed", "paused"]
  progress: Number (0-100)
}
```

#### workout_logs
```
{
  _id: ObjectId
  clientId: ObjectId (ref: users)
  routineId: ObjectId (ref: routines)
  date: Date
  exercises: [{
    exerciseId: ObjectId (ref: exercises)
    setsCompleted: Number
    repsCompleted: [Number]
    weight: Number (optional)
    duration: Number (optional)
    completed: Boolean
  }]
  notes: String
  duration: Number (total minutes)
  rating: Number (1-5)
  createdAt: Date
}
```

#### feedback
```
{
  _id: ObjectId
  clientId: ObjectId (ref: users)
  trainerId: ObjectId (ref: users)
  workoutLogId: ObjectId (ref: workout_logs)
  type: Enum ["client_to_trainer", "trainer_to_client"]
  message: String
  read: Boolean
  createdAt: Date
}
```

#### messages
```
{
  _id: ObjectId
  senderId: ObjectId (ref: users)
  receiverId: ObjectId (ref: users)
  content: String
  read: Boolean
  createdAt: Date
}
```

## API ENDPOINTS

### Auth
- POST   /api/auth/register
- POST   /api/auth/login
- POST   /api/auth/logout
- POST   /api/auth/refresh
- POST   /api/auth/reset-password

### Users
- GET    /api/users/me
- PUT    /api/users/me
- GET    /api/users/:id (trainer only)

### Exercises
- GET    /api/exercises
- POST   /api/exercises
- GET    /api/exercises/:id
- PUT    /api/exercises/:id
- DELETE /api/exercises/:id

### Routines
- GET    /api/routines
- POST   /api/routines
- GET    /api/routines/:id
- PUT    /api/routines/:id
- DELETE /api/routines/:id
- POST   /api/routines/:id/assign

### Workouts
- GET    /api/workouts
- POST   /api/workouts
- GET    /api/workouts/:id
- PUT    /api/workouts/:id
- GET    /api/workouts/history

### Feedback
- GET    /api/feedback
- POST   /api/feedback
- PUT    /api/feedback/:id/read

### Messages
- GET    /api/messages
- POST   /api/messages
- PUT    /api/messages/:id/read
